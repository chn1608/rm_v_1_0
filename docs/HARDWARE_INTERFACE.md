# V1.2 接线说明

当前 MC02、LCD 和 ST-LINK/V2 组合使用 [独立台架接线图](lcd-smoke-wiring.pdf) 和 [Keil5 验证指南](LCD_SMOKE_GUIDE.md)。主板经自身 USB-C 供电，P10 留空。

四页 [接线图](wiring-v1.2.pdf) 依次为整车配电与急停、PC／BLE／SWD、LCD／五向按键、双轮与反馈。图纸为候选审查件，所有针号按对应原理图标注。插拔前切掉电池、USB 和外置供电。针脚从接头的 Pin 1 标记判定，公母头视角可能镜像。只记录证据已确认的 PCB 网络，实物线束仍由硬件负责人核验。

| 线束 | 端点与接线依据 |
|---|---|
| WR-01 主控 | 4S 经独立支路保护接 MC02 XT30 VIN，按板标接正负。板端手册额定 12–24 V，5 V 降压支路不进 VIN。P16.2 为 VCC_IN 网络，保留。 |
| WR-02 电机 | DFR0831 5 V 候选经 K1 触点至 TB H2.1 VM，H2.2 VCC 单独接已核的 3.3 V 逻辑电源。H2.3/.8 回电源地，H1.1 参照 MC02 地。H2.4/.5 为 A，H2.7/.6 为 B。核启动/堵转、温升与模块排针。 |
| WR-03 独立舵机台架 | 额定确认后用独立 UBEC 电源，原方案 7.4 V 候选，电源正、负与控制线按舵机资料及实物核。P11 S3 PE9 只走信号，保留共同参考地，P11 5 V 空置。 |
| WR-04 线圈/急停 | 线圈电源、硬件急停 NC 与独立人工再使能在控制器以外实现断能。PE1/PE0 到 ULN 输入只是线圈命令候选。若选 ULN 内部续流，COM 在急停后与线圈正端同节点，实际扩展板走线和续流波形复核后才定。P15.3 PE2 用独立隔离健康反馈，P15.4 PE3 暂留人工再使能检测，P15.1 留空。 |
| WR-05 调试 | P10.1 PA9 TX → USB-TTL RX，P10.2 PA10 RX ← USB-TTL TX，P10.3 地相连。对端采用 3.3 V TTL，VCC 空置。P1.1 目标参考、.2 GND、.3 SWCLK、.4 SWDIO。 |
| WR-06 蓝牙 | P13.4 PE8 TX → 模块 RX，.3 PE7 RX ← 模块 TX，.2 参考地。候选通讯方向。P13.1 板端 5 V 和 LINK/STA 暂空，通过模块对应资料和实测确认。 |
| WR-07 屏 | 原理图 U13 主板与 TFT 的 U2 同号，优先使用配套接线并断电核对。1 系统 5 V，10 GND。2 CS、3 SCK、4 MISO 保留、5 MOSI、6 BLK、7 RES、8 D/C、9 KEY。手册表的 2 地、10 KEY 与图纸冲突。 |
| WR-08 模拟反馈 | PC4 板侧 VIN 无附加线。PA4、PA6 候选分别读 K1 后 5 V 和 K2 后电池级电压，必须经独立分压、保护及参考地。反馈认定须记录实际触点和残压。UBEC 输出另查。 |

上电顺序由硬件负责人按实际配置批准。底盘、舵机和线圈的回流走配电支路，信号只走参考地。外置 5 V 与板端可控 5 V 分开，USB 可能经二极管进入系统 5 V。PC13/PC14 受控 OUT 不接动力旁路。低压外设与 MCU 单侧上电时均需核回供风险。

测量顺序为断电通断与 Pin 1、限流逻辑上电、控制电平与下拉、假负载急停和复位、按授权逐支路带载。每项拍摄实际线束两端并记录通断、电压、板号、仪器与审核人。
