# 硬件待确认与联调

> 接线图：`chen_bot_v_1_0/docs/wiring_chen_bot_v1_0.pdf`（同名 `.png`）。
> 颜色语义：**绿框=已确认可用**，**黄框=待定/有问题**，**红框=严重问题，必须先处理**。

## 红框（必须先处理）

| 项目 | 问题 | 依据 |
|---|---|---|
| TB6612FNG 供电 | VM 绝对最大 15 V、推荐 ≤13.5 V；4S 满电 16.8 V 超压 | TB6612FNG 数据手册 |
| 主板 5V | UBEC-8A 若切 6 V/7.4 V 档，严禁接主板 5V | 主板额定 5 V |

## 黄框（待定）

分电需自制 XT60 一拖二线束；UBEC 输出档位；USB2CAN 链路（适配器需 CAN2.0/1 Mbps）；
BLE 模块未装；TB6612 带载/堵转未验证；舵机行程未标定；编码器引脚仅预留（`CHEN_FEATURE_ENCODER=0`）；
急停与人工再使能未落地（`CHEN_FEATURE_ESTOP_INPUT=0`）。

## 原待确认表

| 项目 | 阻塞 | 验证证据 |
|---|---|---|
| 实物板号与已接线 | GPIO 冻结 | 断电拍摄板号、连接器两侧和 Pin 1，逐针通断及记录，已签认线束归 L1 |
| LCD U13 与模块座 | 插接、显示和键扫描 | 核 VCC/GND 和所有信号触点，确认模块版本。核 KEY 空闲及五个位置和 PB10/11 功能 |
| BLE02 版次与官方包 | 真实 UART、GATT | 补对应手册、AT 指令、例程。记录供电电平、UUID、模式、模组固件版本及掉线恢复 |
| 供电/回供 | 硬件调试 | 标识 VIN 与受控 OUT，核 4S 支路欠压、电流、USB/VREF 回供和电源跌落 |
| 独立急停与人工再使能 | 一切真实运动 | 假负载验证切断、断线、触点粘连应对、MCU 输出卡高和急停释放后维持禁止 |
| TB6612 和电机 | 带载/限流 | 核模块排针和驱动连续、启动、堵转、温升及走线，失能时测 STBY |
| 独立舵机台架 | 带载/行程 | 核外供、控制电平和失电回供，逐步标定，不执行自动扫角 |
| PC4、K1、K2 | 电压/触点报告 | 记录原始码、VREF、两点标定、开闭时序和残压，测掉电注入 |
| 电流、编码器、位置 | 实测控制闭环 | 确认器件、输出制式和引脚可达性后签核；数据源缺失时返回未安装 |
| 固件实时性和 IWDG | RUN 放行 | 无动力测 RTOS 周期、栈高水位和复位原因，随后经授权逐支路验证。|

资料审查未发现带签字的实物线束记录。已确认的实际接线由硬件负责人识别，工程不能从旧表反推出 L1。
