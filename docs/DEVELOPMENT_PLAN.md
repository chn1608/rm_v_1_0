# 开发顺序与阶段退出条件

| 阶段 | 主线 | 退出证据 |
|---|---|---|
| 0 | 资料、旧表、物理接口及工具链 | 审查、候选表、接线图、待确认清单入库 |
| 1 | HAL 核心、隔离配置、协议、安全、RAM 参数 | 主机自动测试及三种配置的 MCU 构建，列明未启用接口 |
| 2 | 车辆底盘命令、串口诊断和独立舵机台架的软件模型 | 协议与控制模拟；电气签核后增加板级驱动 |
| 3 | Android GATT 和模拟传输 | Kotlin 向量通过，API 35 实机或模拟器验证 |
| 4 | LCD/五向按键 | 先核 U13/TFT 线序，再验证 ADC 窗和局部刷新 |
| 5 | PC 调试 | 帧接收、监测、CSV、回放和有限参数权限 |
| 6 | 集成审查 | 三端协议一致、30 分钟压力、资源及调度报告 |
| 7 | 硬件适配 | 硬件负责人签核、分支逐项实测及授权 |
| 8 | 考核提交 | 视频、技术说明、版本与六项验收证据 |

等待实物时先推进协议、数据模型、PC 回放、键值算法、运动逻辑模拟。每次会话从 [开发状态](DEVELOPMENT_STATUS.md) 和 [测试报告](TEST_REPORT.md) 接续。
