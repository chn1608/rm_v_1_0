# 新旧 GPIO 对照

| 功能 | V1.2 正文旧方案 | 现行工作簿 | V1.2 工程候选及理由 |
|---|---|---|---|
| BLE 数据 | PE7 RX/PE8 TX | 保留 | 保留，P13 按图复核 |
| BLE 状态 | PD14/PD15 | 有条件输入 | 两针留 UART9，等原厂资料/板版 |
| 舵机台架/电机 PWM | PE9/PA0/PA2 | 保留 | 保留，TIM6 接 HAL 时基为 TIM1 让位 |
| AIN1/2 | PE13/PE14 | 保留 | 不变；分别在 P11、P16 |
| BIN1/2 | 未分配 | PC12/PC11 | 保留现行候选，占 SPI3 |
| STBY | PA1 | PC10 | 保留工作簿变更，PA1 固定 Flash D3 |
| K1/K2 | PB0/PA3 | PE1/PE0 | 保留工作簿变更，旧脚固定 Flash D1/D2 |
| 急停/再使能 | PA6/无 | PE2/PE3 | 作为独立低压接口候选，释放急停需人工再使能 |
| 电压 PC4 / K1 / K2 | PC4 / PA4 / 无 | PC4 / PA4 / PA6 | 保留，后一组占 DCMI，仅经保护接入 |
| 电流 | PA7 | 未分配 | 移出 PA7，优先规划 I2C 后备，ADC候选见资源表 |
| PC 调试 | PA9/PA10 | 保留 | 保留；P10 手册文字和原理图不同 |
| LCD | 官方口 | PA5 作数字输入候选，屏未配 | PA5 单通道 ADC，PB10/11 用 BLK/RES，主体针序待核 |
| 编码器 | 无 | 未分配 | 首选外部双通道计数规划，避免 TIM4 CH3/4 被误认作编码器输入 |
| 蜂鸣器/RGB/SWD/IMU | 固定 | 固定 | 物理接口保留，LCD 版本 SPI6 禁用。|

没有把任何变更当成实物换线指令。
