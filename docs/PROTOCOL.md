# 应用层通信协议 V1.0

协议适用于字节流。UART 包、BLE ATT 通知和 GATT 操作边界不作为帧边界。整型均小端，带符号字段为二补码。相同序列号标记请求和应答，无空闲日志文本插入。

| 偏移 | 长度 | 定义 |
|---:|---:|---|
| 0 | 2 | 固定 A5 5A |
| 2 | 1 | 版本 0x10 |
| 3 | 1 | 消息 ID |
| 4 | 1 | 载荷 N，0～64 |
| 5 | 2 | 序列号 0～65535 |
| 7 | N | 载荷 |
| 7+N | 2 | CRC16，低字节先发 |

最短 9，最长 73 字节。CRC-16/CCITT-FALSE，poly 0x1021，init 0xFFFF，refin/refout=false，xorout=0，check("123456789")=0x29B1。覆盖版本至载荷，包含长度和序列号。非期望版本、非法长度或 CRC 错误时从声明帧头下一字节重新寻找帧头。连续两次接收的字节间隔达到 100 ms 时放弃此前残帧。UART 溢出等失步事件清空接收缓冲和残帧。BLE 真实断链接入时也必须清空端口解析器。CRC 只校验完整性。

| ID | 载荷 | 回复及权限 |
|---|---|---|
| 01 PING | 空 | 90 ACK，PC/本地/BLE 只读 |
| 02 STATUS | 空 | 82 STATUS_REPLY，允许 PC/本地/BLE |
| 03 PARAM_GET | u8 参数 ID | 83 PARAM_REPLY，同上 |
| 04 PARAM_SET | u8 ID + u16 值 | 90 ACK，仅本地维护授权且 STANDBY |
| 05 STOP | 空 | 90 ACK，已集成的本地或 BLE 端点可停止。当前仅 USART1 PC 端入口，PC 拒绝 |
| 82 STATUS_REPLY | 下表 | 请求序列原样回显 |
| 83 PARAM_REPLY | u8 ID + u16 值 | 暂只有 ID 1，遥测建议周期 20–1000 ms，默认 50 ms |
| 90 ACK | u8 原命令 + u8 结果 | 0 成功，1 长度，2 未知，3 拒绝，4 越界 |

首版应答为请求驱动，参数 ID 1 为 RAM 中的建议周期。没有自动推送任务和 Flash 持久化。PC 以一个待应答请求工作，超时默认 2 s。串口 TX 忙时可丢弃应答并入错误统计，PC 端可用新的只读查询恢复。没有幂等性假设的命令须单独定义重发规则。

状态载荷共 35 字节。

| 偏移 | 类型 | 含义 |
|---:|---|---|
| 0 | u32 | 运行时间 ms |
| 4 | u8 | 配置 1 SIM / 2 BENCH / 3 RUN |
| 5 | u8 | 状态 0 BOOT / 1 SELF_TEST / 2 STANDBY / 3 LOCAL / 4 REMOTE / 5 FAULT / 6 ESTOP |
| 6 | u8 | 所有者 0 无 / 1 LOCAL / 2 BLE / 3 PC |
| 7 | u8 | 软件接受运动帧标志 0/1 |
| 8 | u32 | 软件锁存故障位，自检 1 / 互锁 2 / 断链 4 / 超时 8 / 设备 16 / 急停 32 |
| 12 | u8 | 电压数据来源 0 invalid / 1 measured / 2 command / 3 estimated / 4 simulated / 5 absent / 6 uncalibrated / 7 stale |
| 13 | u8 | 电压有效标志 0/1 |
| 14 | i32 | 电压 mV，仅在有效时使用 |
| 18 | u32 | 电压采样时间 ms |
| 22、24 | i16 ×2 | 左右轮当前指令，±1000 千分比 |
| 26 | u8 | 参数格式版本 |
| 27、31 | u32 ×2 | 有效帧数、错误/丢失事件累计，允许回绕 |

实装前继续定义动力命令、应用身份绑定、跨 MCU 复位的会话挑战、波形和反馈字段。当前仅在 C 软件模型中验证控制权：授权本地确认再生成控制代次，递增序号按前向半区识别且支持回绕，重复帧不刷新 200 ms 时效。故障清除回到自检，历史命令清空。网络运动命令尚无入口，硬件运动必须等待授权和安全检查。

C、Kotlin 和 Python 共用 [五组基准向量](../soft1/development/Protocol/vectors.txt)。向量覆盖空载荷、参数、序列极值和 64 字节最大载荷，其中最后一行只验证帧编解码。
