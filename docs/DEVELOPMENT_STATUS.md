## 已确定的软件值

5 ms 控制周期、假设的 200 ms 指令时效、100 ms 残帧超时、USART1 115200 8N1，以及 RAM 建议遥测周期 50 ms。它们属于软件启动值。真实 BLE 波特率、UUID、ADC/舵机标定、保护阈值和电源规格待确定。固件仅使用 PC13/14/15 固定电源控制和 USART1。未审动力脚保留复位状态。
