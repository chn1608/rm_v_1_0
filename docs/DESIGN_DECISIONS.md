# 设计决策

| 决策 | 依据及影响 |
|---|---|
| 保留原厂源码为外部本地依赖 | 根目录代码仓库跟踪自有开发和规划，参考仓库与资料历史保持独立。随工程已有 `hard1` 参考快照可复现 ARM 构建 |
| FreeRTOS 原厂 RVDS 端口 | 与现场 Keil Arm Compiler 5 同系，避免引入整套中间件迁移。HAL 时基转 TIM6，RTOS 使用 SysTick |
| 构建与板级配置 | 自有手写 BSP 与构建清单是生效来源。参考 .ioc 只读留存，包括原厂 TIM1 与电源使能初态，不作为本工程可直接再生配置。编译统一 HAL/CMSIS 的 24 MHz HSE 值。 |
| 电控 I/O 分期启用 | PC13/14/15 在 BSP 设低。其余候选动力 GPIO 保持未配置。上电/复位物理禁止由独立保护实现 |
| LCD PB10/11 专用且 PA5 模拟 | TFT 官方模块与通用 I2C2 插座用途冲突，预留 I2C1 于 DCMI PB8/PB9。按键名义值来自 TFT 图纸 |
| 协议 V1.0 小端、CRC-16/CCITT-FALSE | C 和 PC 可独立构建，接收端按字节流重同步。CRC 不提供认证。PC 只读，维护权限由可信本地上下文授予 |
| LCD 台架与主固件分离 | 独立 Keil `LCD_SMOKE` 目标启用 U13 和可选 P10，以分辨启动、显示、键值和串口问题。主程序的 V1.0 二进制协议保持独立。主板仅由 USB-C 供电，串口适配器只连信号和参考地。 |
| RAM 参数 | 配置版本与白名单先落地。等待 Flash 区域、掉电事务和耐久策略核准后再加入持久化 |
