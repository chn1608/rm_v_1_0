## 1. 接线

### 1.1 适配器侧接口（说明书第 3 页）

| 接口 | 类型 | 引脚线序 | 本工程用法 |
|---|---|---|---|
| 电源&通信 | Type-C | — | 接 PC，供电 + 通信 |
| **UART** | GH1.25 **3P** | **GND / TX / RX** | **只用 GND**（第 1 脚）→ 主板 P7.2 |
| **CAN** | GH1.25 **2P** | **H / L** | H→P7.4，L→P7.3 |
| 终端电阻 | 拨码 | ON / OFF | 默认 ON（120 Ω 已接入） |

> 重点：**CAN 接口只有 H、L 两根线，没有地**。适配器的 GND 在 UART 3P 的第 1 脚上，
> 必须把它接到主板地，否则总线没有共同参考点，表现为「发送失败、无 ACK」。
> UART 的 TX/RX 本工程不使用，悬空即可。

### 1.2 主板侧接口

MC02 的 CAN1 与电源共用一个 4 芯端子 **P7（XT30PW-M 2+2）**：

| P7 | 信号 | 接到适配器 |
|---|---|---|
| 1 | VCC_OUT1 | 不用 |
| 2 | INGND | **适配器 UART 3P 的 GND** |
| 3 | CAN1_L | 适配器 CAN 2P 的 L |
| 4 | CAN1_H | 适配器 CAN 2P 的 H |

MCU 侧：`CAN1_RX = PD0`、`CAN1_TX = PD1`（FDCAN1，AF9）。

收发器 U1 由 **VCC_5VS** 供电，原理图注明「使用 CAN 总线需要 USB 供电或者 24V 电源供电
（CAN 芯片使用 5V 供电）」；U1 的 STBY 接地，常开。只插 ST-Link 不接 5 V 时总线不工作。

### 1.3 接线速查

```
适配器 UART 3P: GND ─────────── P7.2  INGND      （必须接）
适配器 UART 3P: TX / RX         悬空
适配器 CAN  2P: H  ──────────── P7.4  CAN1_H
适配器 CAN  2P: L  ──────────── P7.3  CAN1_L
适配器 Type-C  ──────────────── PC USB（供电 + 通信）
```

## 2. 串口协议（CDC，官方格式）

适配器出厂固件即支持，序列口速率设为 10 Mbit/s（CDC 实际速率无关）。

**PC → 适配器（30 字节）**

| 偏移 | 内容 |
|---|---|
| 0–1 | `55 AA` |
| 2 | 帧长 `0x1E` |
| 3 | 命令：`0x01` 转发并回报状态，`0x03` 静默转发 |
| 4–7 | 发送次数 u32 |
| 8–11 | 发送间隔 u32（单位 100 µs） |
| 12 | ID 类型：0 标准帧，1 扩展帧 |
| 13–16 | CAN ID u32（小端） |
| 17 | 帧类型：0 数据帧，1 远程帧 |
| 18 | 数据长度 |
| 19–20 | idAcc / dataAcc |
| 21–28 | data[8] |
| 29 | CRC-8（初值 0，多项式 0x8C，LSB 优先） |

**适配器 → PC（16 字节）**

| 偏移 | 内容 |
|---|---|
| 0 | `AA` |
| 1 | 命令：`0x11` 接收成功，`0x12` 发送成功，`0x02` 发送失败，`0x01` 接收失败 |
| 2 | 长度(6) / ide(1) / rtr(1) |
| 3–6 | CAN ID u32（小端） |
| 7–14 | data[8] |
| 15 | `55` |

**四字节命令**

| 命令 | 含义 |
|---|---|
| `55 02 AA 55` | 握手 |
| `55 03 AA 55` | 停止连续发送 |
| `55 05 <idx> AA 55` | 设置 CAN 波特率；idx 0=1M、3=500k、5=250k、7=125k |

> 收到 `0x02 发送失败` 表示**总线上没有节点应答**：接线、共地、5 V 供电或波特率不匹配。

## 3. 帧映射

| 方向 | 11 位标识符 | 载荷 |
|---|---|---|
| MCU→PC | `0x601` | `data[0]` 段序号，`data[1..7]` 应用数据 |
| PC→MCU | `0x600` | 同上 |

应用层仍是 V1.0 协议帧（`A5 5A` 头 + CRC16），一条状态帧 45 字节，拆成 7 个 CAN 帧。

## 5. 排查表

| 现象 | 处理 |
|---|---|
| `发送失败(0x02)` | 总线上无 ACK：查 P7.3/P7.4 接线、共地、5 V 供电、波特率 |
| `接收失败(0x01)` | 总线错误，多为波特率不一致 |
| 能发不收 | 段序号从 0 开始，检查 MCU 端 `can_link.c` 的 0x601 发送 |
| 握手无应答 | 设备非该协议固件（如 FD 版），换 `--can` + SLCAN/gs_usb |
