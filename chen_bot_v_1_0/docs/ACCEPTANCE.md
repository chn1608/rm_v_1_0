## 安全项自检（软件可验证部分）

| 项 | 结论 | 证据 |
|---|---|---|
| 上电默认禁止动力 | 通过 | `board_safe_defaults()` 先于 HAL；`CHEN_REAL_OUTPUTS=0` 时 `safety_arm` 无成功路径 |
| 通信超时停机 | 通过 | 200 ms 无运动指令 → `FAULT_TIMEOUT` |
| 断链停机 | 通过 | BLE 链路窗口外 → `FAULT_LINK` |
| 控制权唯一 | 通过 | 单 owner + session，他人指令拒绝 |
| 故障锁存 | 通过 | 故障位只增，清除需本地确认且回到自检 |
| 清除后不恢复历史指令 | 通过 | `safety_clear` 清 owner/序号，需重新 arm |
| 指令范围检查 | 通过 | ±1000‰、脉宽 400–2600 µs、参数区间 |
| 未安装传感器不冒充通过 | 通过 | 一律 `DATA_ABSENT` / `DEV_UNAVAILABLE` |

## 未执行项（不得视为通过）

- 实机烧录运行、LCD 显示与按键手感。
- 电机/舵机带载、启动电流、堵转、温升。
- 急停实际切断动力、继电器触点粘连。
- 30 分钟连续运行与压力测试。
- 整车联调与赛事提交。

## 完成判定

中期验收以**实物运行结果**为准。本表"已通过软件测试"只说明逻辑在主机上可复现，
不等于赛事功能已验收。
